# 移动端功能补齐（2026-10-01）

本次对应歌词繁简转换、云盘上传、听歌识曲、Last.fm，以及播放淡入淡出、响度标准化和频谱。不包含外部控制服务、MCP、AI 模型配置或流媒体全量同步。

## 实现范围

- 歌词转换：通过 Tauri 调用与桌面端相同的 `ferrous-opencc`，支持共享类型中的全部转换模式；只缓存当前模式的字典。
- 云盘上传：系统文件选择、查重、秒传导入、NOS 分块上传、提交与发布；检查业务状态和上传偏移，文件句柄在失败后也会关闭。音频文件每次最多读取 1 MiB。
- 听歌识曲：沿用麦克风采集流程，将 8 kHz 单声道 PCM 交给独立 Worker 中的 AFP/WASM，再调用网易云匹配接口；取消时释放 Worker 和麦克风。移动端仍不支持采集其他应用的系统声音。
- Last.fm：浏览器授权、取消、断开、正在播放、播放记录和喜欢同步。iOS 使用 Keychain；Android 使用 Keystore 加密，密文不参与系统备份。授权请求支持取消与超时。
- 音频处理：原生淡入淡出、基于 RMS 的动态响度调整及真实频谱。iOS 在标准化节点前采样；Android 使用当前播放器音频会话的 Visualizer，需要系统音频采集权限。Android 的可视化数据为单声道，左右显示共享同一频谱，不宣称独立立体声分析。窗口隐藏时停止频谱推送。
- 设置：开放 Last.fm、淡入淡出、响度标准化和频谱入口；标准化启用失败时恢复原设置并提示错误。

## 验证边界

已执行前端单元测试、TypeScript 检查、修改文件 ESLint 检查、Android Kotlin 编译、Rust 检查与 OpenCC 单元测试，以及 Android/iOS 前端构建和分包检查。

这些检查不等于完整真机验收：Windows 环境没有执行 iOS Swift 编译，也没有使用真实账号进行云盘上传、Last.fm 授权或播放记录上报。麦克风权限、后台恢复、系统音频路由、音效听感及内存变化仍需 iOS/Android 实机验证。响度调整是 RMS 动态处理，不是离线 EBU R128 分析或完整 ReplayGain 支持。
