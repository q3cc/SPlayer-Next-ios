# iOS 歌曲下载

## 使用

- 在「设置 → 下载配置」开启下载，阅读版权提醒并选择「确认开启」。选择「暂不开启」不改变开关；关闭后再次开启仍提示。中文文案使用用户确认的原文。
- 在非本地歌曲的更多菜单中选择下载及音质，在下载管理页查看进度、取消、重试或播放已完成文件。
- 文件位于「文件 → 我的 iPhone / iPad → SPlayer → Downloads」。目录固定在应用文稿目录，可通过文件 App 复制、移动或分享。
- 下载音质、文件命名、按歌手/专辑分类、重名处理设置生效。关闭功能停止未完成任务，保留已经完成的音频。
- 当前需要保持应用在前台。应用退出后的未完成任务显示为「已中断」，手动重试会重新解析地址、从头下载，不是断点续传。
- 清空已结束记录不删除音频；已完成列表的删除按钮需确认后删除文件。
- 最多保留 200 条任务，达到上限后需清空已结束记录再继续添加；重试替换原记录，不额外占用名额。
- iOS 暂不提供内嵌封面、元数据写入及附加歌词文件导出；不再为不可用的标签功能解析歌词。

## 实现与验证

移动端下载直接调用共用下载源解析服务，通过 Tauri HTTP 流逐块写入 Downloads 下的临时文件，成功后重命名。串行队列避免批量解析风暴及整首音频进入 JS 内存；进度每 200 ms 更新，应用隐藏时停止进度推送。取消中止 HTTP 请求并清理半成品，重试隔离旧任务对象与解析结果。

轻量历史保存到 IndexedDB，不保存下载 URL、歌词或请求配置；文件路径相对 Downloads 保存，以适应 iOS 沙盒根路径变化。没有引入音量功能变更。

回归测试覆盖版权确认、关闭不下载、解析落盘、短写、取消中止、旧解析结果与重试竞争、失败重试、重复文件、重名自动编号、删除失败保留记录、空/网页/截断响应和重启中断处理。

本地验证包含 Web 类型检查、相关 Vitest 回归、Siri 与移动端资源构建和移动端产物检查。当前 Windows/WSL 环境没有 Xcode 或 iPhone：尚未完成 IPA 编译、真机文件权限、锁屏行为及真机内存采样验收。现有 ESLint 环境的 Vue 解析器版本错误仍需单独修复。

真机验收应在开启前取消一次版权弹窗，再确认开启；下载一首授权可用的音频，验证文件 App 可见及离线播放；下载中取消后重试，验证无重复记录；切换命名/分类/重名策略；退出并重开检查中断记录。对比下载前、下载中和结束后的内存采样，确认增长不随音频体积累积。
