## 新插件接口在 iPad 上的使用

在「设置 → 插件管理」导入兼容的 JavaScript 源。只支持解析播放地址的 LX 源继续作为播放来源；声明 `musicSearch` 的源还会出现在搜索页的插件来源选项中。不是每个 LX 源都提供独立搜索。

插件详情按声明展示联网、播放控制、曲库、平台 API 和界面权限。关闭某项后，新调用立即被拒绝；联网请求会被取消，迟到响应不会返回脚本。未声明的权限不能在界面中开启。已有控制插件不会因为升级自动获得联网权限。

- 独立搜索返回保留插件身份的曲目，可加入队列并再次解析播放地址
- 在线搜索沿用现有平台分页；曲库查询限制返回数量
- 平台调用沿用应用已登录账号，但不接受插件覆盖 cookie、域名、代理或请求头，业务响应递归过滤认证凭据
- iPad 的 `notify` 显示带插件名称的应用内提示，不申请系统通知权限
- 插件仍在独立 Worker 中运行，禁用、卸载或超时会终止 Worker；共享运行时保留消息数据净化与调用数量上限

## 平台合并取舍

- **启动与更新**：保留移动端静态启动模块图，使用上游启动交接；设置页按需加载。原生 IPA/APK 下载和安装事件转换为上游带版本号的更新状态快照，安装失败保留重试入口
- **播放**：保留 iOS 原生音频引擎；修复迟到过渡响应、暂停态地址恢复与失败跳曲。桌面双槽交叉过渡不在移动端启用，移动预载入口也不会调用不支持的引擎能力
- **流媒体**：采用完整分页、失败保留快照、服务端确认收藏值和媒体身份代次隔离。播放才创建上报；下载不记播放，缓存播放不等待网络认证。服务器账号或地址变更后旧曲目和下载不能被当作新账号曲目复用
- **网易云接口**：移动端沿用原生 HTTP 加密协议；上游依赖 Electron 隔离网页的 Web 客户端不进入 iOS。相关歌单/收藏入口映射到原生协议，账号切换取消旧会话结果。已登录账号的真实写入操作没有在本次测试中执行
- **加密兼容**：模拟器发现浏览器 Buffer 不支持上游新增的 `base64url` 编码；改用等价的无填充 URL 安全编码，测试改用浏览器 Buffer 并验证与 Node 加密协议互通
- **设备信息**：登录设备名称使用 SPlayer 平台名，不读取或发送编译电脑用户名
- **歌词与界面**：同步 lyric-kit 0.6.1、lyric-dom 0.2.1、歌词解析与设置、流体背景就绪预览；保留 iPad 隐藏停帧、触摸和系统音量控制
