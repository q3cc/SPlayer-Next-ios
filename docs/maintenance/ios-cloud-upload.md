# iOS 云盘上传

## 操作与行为

登录网易云账号后，在云盘上传窗口选择音频文件。系统文件选择器支持多选；取消不新增任务，重复点击不会打开多个选择器。读取失败会提示重新选择。

文件进入队列后依次读取摘要、检查云端是否已有音频、执行秒传导入或正常上传，最后提交歌曲信息并发布。全部任务处理后刷新云盘；失败项可重试。队列最多保留 200 项，新任务优先淘汰已结束记录；待上传任务已满时停止继续添加并提示。

请保持应用在前台直至上传完成。此版本不提供退出应用后恢复任务或断点续传。iCloud 文件需先由系统下载到设备。原生文件上传使用系统网络设置，不使用应用内手动代理；平台 API 请求仍遵循原有代理配置。

## 实现边界

- 选择器调用 Tauri dialog，多选音频；fs:allow-stat 允许读取所选文件信息，具体路径由选择器授予访问权限。
- 原生 prepare_cloud_upload 只读取应用沙盒内的常规音频，64 KiB 分块计算 MD5，不把音频传入网页内存。
- 原生 upload_cloud_file 使用 URLSession 从磁盘发送请求体，只允许 HTTPS 的网易 NOS 域名，拒绝重定向转发上传凭证。
- 原生进度每 200 ms 更新，后台不推送高频进度；完成和失败后释放会话及订阅。
- 查重、凭证、信息提交和发布均复用仓库现有网易接口；平台业务错误不会标记成成功。音频传输成功后，只有发布成功才算完成。
- 未修改音量实现；NativeAudioPlugin 仅增加云盘上传组件，命令及权限在同一插件注册。

## 验证范围

Vitest 覆盖系统选择器参数、取消和多选、文件 URL、读取错误、重复点击、容量上限、监听释放、秒传、正常上传、失败重试、发布失败及上传域名限制。原生契约测试仅检查桥接注册和源码约束，不等同于 Swift 编译或真机测试。

当前 Windows/WSL 环境没有 Xcode/iPhone，不能验证 IPA 编译、账号实际上传或真机内存变化。真机验收需分别上传可秒传的文件和新音频，核对云盘刷新、网络失败重试、iCloud 文件选取、大文件上传期间内存，以及前后台切换行为。修改了原生 Swift，需要重新构建 IPA，单独更新网页资源不会生效。
