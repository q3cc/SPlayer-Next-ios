# iOS 缓存与离线播放

## 使用

在设置 → 本地缓存开启歌曲缓存。歌曲正常播放后会尝试额外缓存完整音频，请保持应用在前台直至缓存完成；只有完整写入的歌曲才能离线播放。缓存命中发生在在线地址解析之前，可从已保存的歌单或播放队列播放。切换音质需重新缓存，缓存不负责离线加载尚未保存的远程歌单。

流媒体服务器歌曲需另行开启流媒体缓存。试听音源不缓存。本地导入文件无需重复缓存。缓存功能不是歌曲下载开关的一部分；长期保留的音乐请使用下载或导入功能。

## 存储与限制

- 音频位于应用 Cache/offline-songs；系统可能回收此目录，不能视作永久离线保留。
- SHA-256 缓存键作为文件名，不持久化下载链接、Cookie 或访问令牌。
- 单个活动下载，不积累等待队列；快速切歌时新缓存任务可能跳过，不影响播放。
- HTTP 流分块写入临时文件，完整响应校验后重命名。失败、取消、清理及重启会清理临时文件。
- 按最近使用时间淘汰，设置的容量限制作用于已完成缓存；下载期间需要额外临时空间。0 表示不限容量，但元数据和文件数量仍限制为 2048 项。
- 自动淘汰保留最近命中的歌曲，可能暂时超过调低后的上限。手动清理会删除全部歌曲缓存，可能中断正在播放的缓存歌曲。
- 歌词缓存统计按 localStorage UTF-16 字节估算；仅清理歌词、TTML 和匹配结果前缀，不清理账号、配置、曲库或 Downloads。
- iOS 使用固定沙盒目录，不展示更换目录、打开文件管理器等桌面操作。

## 验证

自动化覆盖流式短写、离线命中、重启恢复、系统回收、音质隔离、试听不缓存、开关、容量淘汰、取消竞态及用户数据隔离。

仍需在真机执行：开启缓存并播放至缓存完成 → 开启飞行模式 → 从原队列重播；切换音质、强制退出重开、清理缓存、调整容量限制，确认下载文件仍在。应采集播放与缓存前后的内存峰值；当前开发环境无法提供 iOS 真机内存样本。
