# iPad 原生版本

## 使用与实现

原生应用保留 B 版首页、侧栏、搜索和迷你播放器的内容结构；全屏播放器分为 Next 原版与 Apple Music 两种布局，只在“设置 → 外观设置 → 播放器主题”切换，卡片用当前封面预览两种布局。原版歌词开关位于左上角，歌曲信息左对齐，竖屏进度条在播放键上方；AM 使用顶部短横条、渐隐大封面，打开歌词后改为顶部小封面和歌曲信息。两者共享 [Apple Music-like Lyrics](https://github.com/Steve-xmh/applemusic-like-lyrics) 风格的歌词舞台。导航和悬浮控制使用系统液态玻璃，列表保持清晰背景。

界面由 SwiftUI / UIKit 渲染，不使用 WebView。平台业务复用最新共享 TypeScript 接口，在 JavaScriptCore 中无界面运行；第三方音源另在 QuickJS 中隔离执行。它不是完全不含 JavaScript 的应用。

Bundle ID 为 `top.imsyy.splayer-next.native`，可与旧 Tauri 应用并存。登录、曲库和设置独立保存，不自动读取旧应用沙盒。

### 已接通

- 网易云、QQ 音乐、酷狗搜索，网易云推荐歌单、每日推荐和私人 FM，在线曲目解析与 AudioStreaming 原生音频引擎播放
- 三平台二维码登录界面、登录状态检查和 Keychain 保存；每日推荐、云盘等需要对应平台账号
- 本地文件导入、AVFoundation 元数据与封面提取、艺术家/专辑/文件夹浏览
- 喜欢、最近播放、持久播放队列和进度；重启恢复不自动播放
- 本地歌单创建、加歌、移除和删除，推荐歌单收藏；这些收藏不自动同步到平台账号
- 网易云云盘分页浏览与播放，不包含上传
- 队列重排、顺序/循环/随机、锁屏媒体控制、音频中断处理、耳机断开暂停、系统音量和 AirPlay
- 在线网易云 LRC/YRC、QQ LRC/QRC、酷狗 LRC/KRC 与翻译；逐字数据使用真实毫秒时间戳扫亮，普通 LRC 逐行显示；导入本地 UTF-8 LRC
- 歌词点击跳转，手动浏览后恢复跟随；横屏封面在左、歌词在右，原版控制栏位于底部，AM 控制区在左侧封面下方；竖屏切换封面/歌词
- 浅色/深色/系统主题；iOS 26+ 系统玻璃，旧系统使用原生材质；减少动态效果时停用连续背景动画

### 启动与歌词动效

启动页复用原版 Logo 字形、Poppins 品牌字体、三点及版权文字，等待本地曲库加载和入场动画后退出，网络推荐不阻塞进入首页。字体从仓库 `public/fonts/logo.woff2` 转换为 `Resources/Logo.ttf`。

歌词前奏或已知句尾到下句之间至少五秒的间奏显示三点，随真实播放进度亮起；暂停冻结、回拖重新计算，开唱时消失。没有句尾时间的普通 LRC 不推测句间间奏。Next 原版切换歌词不改变底部控制栏位置。AM 竖屏进入歌词面板时默认隐藏控制区；底部箭头唤回后，播放键和歌词按钮回到原位，右上角箭头再次隐藏。横屏不隐藏控制区。AM 队列在详情舞台内展开，而不是另开队列弹窗。

播放器作为原页面上的原生覆盖层显示。下拉时露出打开前的页面，保留原有主题、导航和滚动位置；短拖回弹，超过关闭阈值后收起。拖动条的点击与拖动分开识别，避免松手误触关闭。

### 流体、设置与控制

设置页按 main 分支的分类组织：常规、外观、播放、歌词、桌面歌词、网络与服务、下载配置、本地与缓存、插件管理、其他和关于，侧栏使用系统设置式彩色图标。iPad 上为左侧分类栏加右侧分区表单，窄屏折叠为分类列表，并记忆上次打开的分类。各项名称、说明、取值范围和默认值沿用 main 的 `src/settings/categories`；main 中尚无原生实现的分类（Siri、AI、媒体源、代理、Last.fm 等）不显示。原生独有且已接入的项（歌词水平对齐、副行字号、保持屏幕常亮、均衡器、播放控制、音频输出）放在最接近的分类中。

流体直接执行锁定的 AMLL **0.5.2** 双三次 Hermite 网格和 32px 纹理调色/模糊算法，原版 GLSL 的网格采样、旋转、节拍缩放、抖动、暗角和过渡合成移植到 Metal。`prepare-fluid.mjs` 从安装依赖生成算法资源；更换 AMLL 版本会明确停止构建，需先复核着色器兼容性。退出播放器或进入后台停止渲染；暂停冻结可选，旋转仍更新静止帧。

“设置 → 外观设置 → 播放页”提供三种背景、流速 0.1–10、渲染比例 0.5–2、帧率 24–120、暂停冻结和真实低频节拍。频谱采用 2048 点 Hamming 窗和 128 个 80–2000 Hz 对数频段，不使用随机动画伪装音频信号。

“播放器与歌词”包含全屏封面、封面/歌词比例、无歌词居中、播放来源、原版 HCT 封面跟色、屏幕常亮，以及字号、字重、翻译、罗马音/注音、对齐、混合模式、缩放/模糊/逐字效果、六组弹簧预设和自定义参数。底部双声道频谱可调柱宽和方向。歌词跟随与原版 lyric-dom 一致，把当前行的垂直中心对齐到“对齐位置”（默认视口 35%），长短行切换时滚动目标不随行高变化。Next 原版移动端按上游规则始终在闲置五秒后淡出控制栏，触摸恢复；AM 使用上述独立的歌词沉浸规则。

播放器菜单的均衡器（十段、前级、九种预设）、0.5–2 倍速、±12 半音与保调、AB 点及 0.1 秒微调、定时关闭和等待整曲结束均连接真实音频状态。音频复用仓库的 AudioStreaming 和原 iOS 响度算法，支持淡入淡出、响度标准化及在线解析音质选择。上次歌曲总会恢复；“记忆播放进度”决定是否回到上次位置，“自动播放”决定启动后是否直接播放，默认恢复进度但不自动播放。

歌词复制可选择行、全选/反选、包含翻译/罗马音、空行和署名，也可复制原文或调用系统分享。“生成歌词海报”按 Next 的 `utils/lyric/poster.ts` 用 CoreText 绘制：720pt 宽、3 倍像素（超长时按 16000px 上限降采样）、封面 70px 模糊加 1.2 饱和度并压暗 50%、对唱行右对齐、底部 “Made by SPlayer Next” 水印；文件名为“歌名 - 歌手 - 歌词分享.png”，可系统分享或只申请“添加照片”权限保存到相册。歌词偏移按曲目持久保存，最多保留 256 项。文本歌词导入复用 lyric-kit，可解析 LRC、TTML 和支持的逐字文本格式；不将压缩 KRC 文件当作 UTF-8 文本解码。

### 网易云账号

登录网易云后与原版一致展示账号内容（共享服务 `src/mobile/native/account.ts`）：

- **顶栏**：账号按钮变为头像胶囊（头像、昵称、黑胶 VIP 标识），点开资料卡显示等级、签名和歌单 / 专辑 / 歌手收藏数，点计数进入“我的收藏”对应分类；卡片内可进入平台账号页或退出登录。退出时先结束服务端会话再清除本地 cookie。
- **首页**：问候语附上昵称，“推荐歌单”变为“专属歌单”，并增加“雷达歌单”；登录或退出后自动切换。
- **侧栏**：“我的歌单”可切换本地 / 在线，在线为账号自建歌单（不含“我喜欢的音乐”）；另有“收藏的歌单”分组。歌单按原版规则拆分：前 `createdPlaylistCount` 个为自建，其余为收藏。
- **我喜欢的音乐**：分“本地 / 在线”，在线为账号的“我喜欢的音乐”歌单。
- **我的收藏**：分“歌单 / 专辑 / 歌手”，内容来自账号收藏；专辑和歌手可打开曲目列表。应用内收藏的推荐歌单与本地歌单仍在“歌单”分类下。

QQ 音乐与酷狗暂只显示登录昵称。

### 私人 FM、心动模式与红心

私人 FM 使用网易云接口和独立曲池，剩余一首时续取；FM 中上一首不可用、循环显示 ∞，随机键变为“不喜欢”（回报已播放秒数），队列键打开模式选择（默认/熟悉/探索/场景及三组场景标签）。心动模式调用网易云智能播放。收藏网易云歌曲同步红心，失败回滚；未登录只保存本地。锁屏与控制中心显示专辑和封面。

### 分语言歌词字体

共享歌词解析调用 lyric-kit `applyLyricLanguages` 按整首歌识别每行语言（zh-CN / ja / ko / und-Latn），原生端据此选择字体：语言专属字体 → 歌词字体 → 系统字体，与原版 CSS 回退顺序一致。翻译、音译和注音按自身文字识别。“设置 → 歌词设置 → 歌词字体”使用系统字体选择器，并按语言只列出支持该文字的字体。歌词舞台、歌词海报和歌词小窗共用该设置。

### 桌面歌词（画中画）

移植自 Tauri 版 `plugins/lyric-pip`：AVSampleBufferDisplayLayer 逐帧绘制 640×160 画面（旋转唱片 + 最多三行歌词），系统画中画显示，应用进入后台仍可读取引擎实时进度。选项与 iOS 版一致：帧率 5–60（默认 20 FPS）、双行歌词、显示音译和翻译、字号 16–40、高亮/普通颜色，设置页带实时预览。可在设置页或播放器菜单开关；小窗内播放/暂停直接控制原生播放器。

### 下载

对应 Next 的下载功能，默认关闭，需在“设置 → 下载配置”启用；启用后歌曲菜单、播放器菜单和歌单“批量下载”出现，侧栏/音乐库出现“下载管理”（待下载 / 下载出错 / 已完成，可播放全部、重试、移除、删除文件、清空记录）。任务串行执行并持久保存，重启时下载中的任务标记为中断。音源与播放共用解析（自定义源优先），按文件头判断实际格式。MP3 写入 ID3v2.3，FLAC 替换 Vorbis Comment 与 PICTURE 块并保留其他字段，M4A 直通重封装写入元数据。下载文件始终加入应用曲库（封面缩略图、TTML 歌词，可离线播放）；开启“保存到「文件」App”后按文件名模板、分类和重名规则在“文件 › SPlayer Native › SPlayer 下载”中硬链接一份，并可额外保存 LRC/TTML。iOS 播放与下载链接相同，因此不提供“模拟播放下载”和下载目录选择。

### 过渡与动画

“设置 → 外观设置 → 过渡与动画”对应原版 `softwareAnimations` 分组：

- **减弱动画**：系统“减弱动态效果”或此开关任一开启即生效。页面切换只保留 150ms 淡入淡出，播放器改为淡入加 12pt 位移，歌词、启动页和间奏动画按原有规则停止位移；与原版 `reduced-motion.css` 一致，液态玻璃改为 92% 不透明底色。
- **页面切换**：无 / 淡入淡出 / 滑动 / 缩放，时长与原版 `route-*` 过渡相同（离开 0.1s，进入 0.15s）。
- **共享元素过渡**（默认关闭）：首页推荐、收藏歌单和本地歌单的封面飞入歌单详情头部（260ms），返回时飞回原卡片；底栏封面与全屏播放器封面之间互相飞行（展开 360ms、收起 340ms），播放器同时淡入淡出。飞行期间页面直接切换，只有封面移动。实现为根视图覆盖层绘制一张缩略图，按锚点在两端位置之间插值；目标未挂载或不在可视区时直接切换，不做过渡。

歌单详情页新增与原版一致的头部：160pt 封面、标题、来源与类型图标、简介、歌曲数和操作按钮。封面先显示已缓存的缩略图，再换成大图。

### 界面风格

原生界面以上游 `upstream/dev` 的 Vue 实现为准（本仓库 `src/` 可能落后）。规范整理在 `.claude/skills/splayer-native-ui/`（色板、字号、圆角、组件与页面尺寸，附源码出处），共享实现在 `NativeTheme.swift`：

- 色板令牌对应原版 `--s-*`：页面 `nativeSurface`、卡片与行 `nativeSurfacePanel`、弹出层 `nativeSurfaceBright`，强调色 `nativePrimary` 为默认主题由 #fe7971 生成的色调（浅色 #2C1513、深色 #FFDAD6），不再使用系统黑白或蓝色。
- 共享组件：SButton（`NativeSButton` / `NativeButtonStyle`）、页面标题区、区块标题、空状态、STabs（bar / segment）、SCard、封面卡片与网格、标题区搜索框。
- 内容层为实色面板加细边框；液态玻璃只用于顶栏按钮、搜索胶囊、底部播放栏和标签栏。
- 外壳：侧栏改为实色面板 + 右侧边线，菜单为原版 SMenu（42pt 项、选中 primary/10 与 3pt 指示条），顺序与原版一致；底部播放栏为原版 80pt 通栏（进度条骑在上边线，左歌曲信息与喜欢/更多、中间 38/44 控制组、右侧时间与工具栏），竖屏为 72pt 迷你栏。
- 首页补齐 hero 卡片（每日推荐 / 本地随机 / 我的最爱）；歌曲列表补齐表头、专辑列、“共 N 首”元信息和标题区搜索，行内操作改为长按菜单；设置改为原版对话框样式（左栏搜索与分类、分区竖条标题、逐项卡片）；统计、下载、收藏、云盘按原版尺寸重排。

侧栏默认完整显示；“外观 → 布局 → 折叠侧边栏”（对应原版 `appearance.sidebarCollapsed`，默认关闭）开启后收为 64pt 图标栏（只留标志与图标，隐藏分组标题和新建歌单按钮，宽度 300ms 过渡）。与上游不同，窄窗口不强制收起侧栏。其余窄窗口规则按上游 dev 响应窗口宽度（`NativeLayout.isNarrow` / `isCompact`）：<1200 顶栏账号胶囊只留头像；<1024 顶栏搜索框收窄为 160，播放栏改紧凑排布（仍 80pt：左侧紧凑控制组，中间为 40pt 封面的歌曲信息、时间与进度条，右侧工具栏），只在分屏或台前调度的 900–1024pt 窗口出现。页内断点改读窗口宽度（环境值 `nativeViewport`），不再由页面宽度加侧栏宽度反推。

### 歌曲列表与播放行为

“外观设置 → 布局 → 歌曲列表样式”提供舒适（76pt 带描边卡片、48pt 封面）和紧凑（56pt 无边框、36pt 封面）两种，尺寸取自原版 `SongList.vue`。行首序号为播放按钮：当前曲目切换播放/暂停，其余按“播放设置 → 播放行为 → 歌曲播放按钮行为”仅播放当前（插入当前曲目之后）或播放全部。点击整行对应原版双击，替换为整张列表；搜索页按“搜索页播放”设置，默认仅播放当前。

### 收听统计

对应原版 `core/player/stats.ts` 与 `playStats.ts`：按曲目身份与播放态累计实际收听时长（扣除暂停），切歌、播完（单曲循环每圈一条）时结算，少于 5 秒不记录。记录保存在 `play-stats.json`（曲目快照按 id 去重）；暂停和退到后台时同时保存进行中的会话，被系统结束后下次启动补记。收藏变更只保留两周，用于“本周新增收藏”。

- **首页**：头部显示本周时长、新增收藏和连续收听天数，副标题每次进入从问候语、连续天数、本周时长、周环比、新增收藏和最近播放中随机挑选；“继续聆听 / 反复聆听”取最常播放的 6 首，最高次数不少于 2 次时显示为“反复聆听”。
- **统计页**（侧栏，或音乐库顶部的“统计”）：曲库概览（歌曲、专辑、歌手、总时长、总大小）、近 90 天聆听足迹、播放时段曲线、音频格式与无损占比、最常听的歌曲 / 专辑 / 歌手前 10。口径与原版 SQL 一致：周从周一开始，同次数按最近播放排序，歌手按“ / ”拆分后分别计数。

### 关于软件

与 main 的 `AboutSettings.vue` 同步：关于软件（标志、版本、检查更新）、特别致谢、开发人员（iOS 版本贡献者只统计相对 `SPlayer-Dev:main` 新增的提交，原版贡献者取原仓库列表，各显示前 6 位，可展开）、社区与资讯、环境信息（提交、日期、构建、系统，可一键复制）。提交与日期由 `prepare.sh` 写入 `build-info.json`。检查更新沿用 main 的版本号规则，只看带 IPA 的正式版；原生版本的安装包不在 Releases 发布，发现新版本时只打开发布页，不下载 IPA。原生端额外保留“开源许可”页，展示随应用分发的许可证全文。

### 听歌识曲

顶栏搜索旁的波形按钮打开识曲。与 main 的麦克风识曲一致：点“开始识别”时才申请麦克风权限，暂停当前播放，采集 8 秒并重采样为 8 kHz 单声道，用 JavaScriptCore 运行与广播扩展相同的 `src-tauri/ios-recognition/afp-runtime.js` 生成 AFP 指纹，再经后台服务的 `recognize` 动作调用 NCM `audio_match`，展示前三个候选，可直接播放或搜索。识别结束、出错或取消后恢复播放，指纹运行时每次识别后释放。

尚未移植 main 的“系统声音”来源：它依赖 ReplayKit 广播扩展与 App Group 签名，模拟器无法运行，需单独新增扩展 target 并在真机验收。模拟器上的麦克风需要 macOS 允许“模拟器”使用麦克风，否则输入格式为 0 Hz，界面提示“未找到可用的音频设备”。

### 自定义源怎么用

进入“设置 → 插件管理”，通过 HTTPS 地址或本地文件导入。新插件默认关闭；查看声明的权限后启用。具备独立搜索能力的插件会提供自己的搜索入口。普通音源为平台搜索得到的曲目解析播放地址。

插件可按授权使用网络、播放控制、曲库、平台接口和界面通知。关闭权限或插件会停止对应运行实例及请求。平台接口复用已登录状态，但返回插件之前过滤凭据，不允许插件覆盖认证请求字段。插件无法直接访问文件系统、宿主对象或 Keychain。

QuickJS-NG 固定为 **0.17.0**，源码和许可证保存在 `Sources/CQuickJS/vendor`。不编译其系统文件/进程模块，不使用 JIT。单实例堆内存 64 MiB、计算片段 2 秒上限；网络、消息、持久存储和请求数量均有上限。未知来源插件仍应先审查，启用即授予所勾选能力。

## 编译与测试

需要 macOS、Xcode、Node/pnpm 和 XcodeGen。仓库根目录执行：

```sh
pnpm install --frozen-lockfile
bash src-tauri/ios-native/scripts/prepare.sh
cd src-tauri/ios-native
xcodegen generate
swift test
xcodebuild -project SPlayerNative.xcodeproj -scheme SPlayerNative \
  -destination 'generic/platform=iOS' -configuration Release \
  -derivedDataPath build/device CODE_SIGNING_ALLOWED=NO build
```

`prepare.sh` 从共享 SiriRuntime、AudioAnalysis、业务入口、AMLL 和封面取色源码生成本地资源，不要手改生成副本。修改共享接口或 runtime 后重新执行。

模拟器 UI 测试须使用 Xcode 生成的模拟器签名，不能只在构建后手动补签：

```sh
xcodebuild -project SPlayerNative.xcodeproj -scheme SPlayerNative \
  -destination 'platform=iOS Simulator,id=<iPad UDID>' \
  -derivedDataPath build/simulator -resultBundlePath build/NativeUITests.xcresult \
  CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- \
  -collect-test-diagnostics never \
  -only-testing:SPlayerNativeUITests/NativeAppTests test
```

`NativeAppTests` 验证横竖屏导航、中文搜索、导入取消/重开、本地真实播放和页面无 WebView。`NativeRefreshTests` 依赖外网以及安装的旧应用，按单个测试选择执行；它用于原版截图对照和真实平台播放，不放入离线回归要求。

Swift 单元测试还覆盖原版网格/纹理、真实 PCM 播放、变调后的频率移动、EQ 增益、响度算法、AB/定时取消、复制筛选及旧快照兼容性，以及语言识别与字体回退、海报尺寸与降采样、ID3/FLAC 标签改写、下载命名规则、小窗歌词行规则、收听统计汇总与榜单口径、会话计时与补记，以及“仅播放当前”的队列插入；共享歌词测试覆盖 TTML、罗马音、原文传递、行语言和下载歌词导出。曲库保护、持久队列/歌单、取消竞态和插件权限测试继续保留。共享宿主校验测试位于 `src/mobile/native/pluginHost.spec.ts`。

真实第三方音源测试需显式提供已经审查的脚本路径，默认跳过：

```sh
NATIVE_REAL_PLUGIN_PATH=/absolute/path/source.js \
  swift test --filter NativePluginTests/testRealCustomSourceWhenExplicitlyProvided
```

GitHub Actions `.github/workflows/ios-native-ui.yml` 构建独立应用、运行测试并打包未签名 IPA。IPA 必须使用有效证书签名后才能安装；模拟器构建不等于真机签名或上架验证。

## 与 B 版的视觉差异

两套播放器仍使用 SwiftUI / UIKit 排版和系统字体；流体已改为原版算法和 Metal 着色器移植，不再使用 MeshGradient。已接通原版全屏封面和 AM 沉浸行为，但不能据此称为所有页面逐像素一致。

尚未等价移植的播放器能力包括：完整 AMLL DOM 歌词引擎及其专属优化/多组弹簧参数，以及歌曲评论。现有歌词舞台使用原生文本排版与弹簧动画；新增参数和流体算法不代表这些缺项已经完成。

界面仍有未还原处：首页歌手推荐与新碟上架、搜索页的专辑/歌手/歌单分类、歌单详情滚动折叠标题、歌词侧边工具（原版仅悬停显示，触控设备不可见）、评论；系统控件（菜单、选择器、开关）保留 iOS 外观。

共享元素过渡在原生端是覆盖层绘制的缩略图飞行，不是浏览器 View Transition；返回列表时原生页面不恢复滚动位置，卡片不在可视区时直接切换。统计页的专辑与歌手榜点击后进入本地专辑 / 艺术家页，尚无在线专辑与歌手详情页可跳转。

## 尚未迁移与设备验收

以下能力仍需后续实现：Subsonic/Jellyfin/Emby 媒体服务器、系统声音识曲、歌曲磁盘缓存、云盘上传、Siri、多语言切换、旧应用数据迁移。原生音频已复用旧 iOS 的 AudioStreaming；桌面 FFmpeg 的全部格式支持仍不能据此推定。

三平台二维码流程已有代码，但实际扫码授权需要账号持有人完成，不能用二维码生成测试代替登录验收。真机还需验证后台长时间播放、来电恢复、蓝牙/有线耳机、AirPlay、实际音频输出和内存/耗电。当前版本可以作为独立原生版本试用，尚不能替代旧应用的全部功能。
