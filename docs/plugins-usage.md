# 插件使用指南

插件可添加独立曲库、解析播放地址、补充歌词与封面，或联动播放状态。本文介绍如何安装和管理插件。编写插件见[插件开发](/plugins/development)。

## 打开插件管理

**设置 → 插件管理**。每个已安装插件以卡片展示：名称、版本、作者、运行状态与支持的音源。

## 安装插件

可选择以下方式：

- **插件市场**：在插件市场中选择插件并点击安装。
- **本地导入**：选择一个 `.js` 脚本文件。
- **在线导入**：粘贴一个指向 `.js` 脚本的 HTTPS 链接（如 GitHub / Gitee 的 raw 地址）。

LX 脚本及压缩脚本的支持范围见 [LX 兼容](/plugins/lx)。

## 启用 / 禁用 / 卸载

- 新安装的插件会**自动启用**。
- 在卡片上可随时启用或禁用插件，可同时启用多个插件。多个插件解析同一内置来源时，按插件优先级选用；独立曲库中的歌曲由所属插件处理。
- 插件若声明了设置项，可在卡片上打开**设置**进行配置。
- **卸载**会删除脚本及其本地数据，且不可恢复。

状态徽章：**已导入**、**正在加载**、**可用**、**加载失败**（卡片下方会显示原因）、**已禁用**。导入成功只表示脚本已保存；需要联网初始化的脚本会保持加载状态，完成初始化后才显示可用。

## 查看详情与管理权限

点击已安装插件的卡片，打开详情弹窗。在「权限」中可逐项开启或关闭插件申请的权限：

| 权限       | 允许插件做什么                                                   |
| ---------- | ---------------------------------------------------------------- |
| 网络请求   | 请求外部网络服务                                                 |
| 播放控制   | 播放、暂停、切歌和修改播放队列                                   |
| 界面扩展   | 添加菜单和发送系统通知                                           |
| 音乐库访问 | 搜索本地音乐库                                                   |
| 平台接口   | 使用软件当前的平台登录状态调用接口，包括收藏、修改歌单等账号操作 |

插件声明的权限默认开启，可在详情中关闭；更新插件会保留你的选择。

## 搜索与播放

在搜索页切换到「插件」，从右侧下拉框选择音源，输入关键词即可搜索歌曲。来源由已启用且就绪的插件提供，支持播放的歌曲可直接播放或加入队列。

队列中的插件歌曲会随应用保存，重启后仍可播放。关闭或卸载对应插件时，歌曲会保留在队列中，但播放会提示来源不可用。重新启用或安装相同插件即可继续使用。

### iOS / Android 自定义音源

在 **设置 → 插件管理** 选择「本地导入」或「在线导入」。在线导入需要 HTTPS 脚本直链，不是 GitHub 仓库首页或文件预览页；本机调试地址可使用 HTTP。

[pdone/lx-music-source](https://github.com/pdone/lx-music-source) 收录了多个独立脚本，可从其 README 获取各脚本直链。应用不内置这些脚本，也不会自动安装它们。请自行核实来源与使用要求。

- 当前歌曲平台支持网易云、QQ 音乐与酷狗；脚本额外声明的平台不会自动增加到搜索列表。
- 可同时启用多个音源：优先使用官方完整音源，失败后按已配置的插件顺序尝试，最后才考虑已允许的试听片段。
- 脚本显示「可用」表示已完成加载，不代表其第三方服务、所有歌曲或所有音质都能使用。
- LX 脚本的更新通知不会自动替换代码。点击「查看更新」，下载新版脚本后重新导入；同一身份的脚本会保留启用状态和设置。
- 移动端向脚本报告 `lx.env = "mobile"`，协议版本保持 `2.0.0`。本次兼容不包含 Siri 在后台执行自定义脚本。

若显示加载超时，可能是脚本的初始化服务未响应；若播放时提示密钥无效、限流或服务不可用，需要向音源作者确认。重新导入无法修复第三方服务本身。

## 常见问题

**导入后状态显示「加载失败」？**
查看卡片下方的错误信息，通常是脚本本身的语法 / 运行错误，或脚本声明的 API 级别高于当前版本（需等待应用升级）。

**插件崩溃会影响应用吗？**
插件在独立宿主进程中运行，宿主崩溃后应用会尝试重启它；期间其他插件也可能短暂不可用。

**插件请求很慢？**
插件的网络请求会遵循系统代理，速度取决于目标接口与网络状况。
