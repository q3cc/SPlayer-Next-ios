# SPlayer Next iOS / iPadOS 2.0.0

- 支持 Siri 搜歌、播放与切歌，可在设置中配置。
- 改善后台播放、控制中心信息和小窗歌词同步。
- 支持 iOS / iPadOS 26 的全屏封面，使用静态画面的封面视频。
- 播放器音量按钮直接打开系统音量滑条，显示实际系统音量。
- 修复 QQ 音乐、酷狗试听音源的进度条时长。
- 优化启动动画、iPad 横竖屏布局，并缩小 IPA 体积。

提供未签名 IPA，需要自行签名安装。Siri 需要签名保留对应权限；全屏封面的呈现由系统决定。

自动冒烟测试已关闭，保留常规 CI 与构建测试。本版全屏封面、音量调节已由用户真机确认，其余功能不代表全部经过真机回归。
